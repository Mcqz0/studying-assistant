# studying-assistant

## Overview

- This project aims to build a full-stack web application catering to students, providing a practical support tool that combines document handling, retrieval and optional AI-assisted features.

## Planned features

- Upload PDF and text files
- Extract and store document texts
- Search for relevant sections in the uploaded documents
- Ask questions about the uploaded materials
- Save previous chat history

## Tech Stack

- Backend: FastAPI
- Frontend: React
- Database: SQLite
- Deployment: Docker / Render
